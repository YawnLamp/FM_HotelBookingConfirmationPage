Goals Reached:
- Easily the most CSS styling I have ever done on a project, made a few aesthetic choices, mainly that I did not want to overlap the two hero cards in the center of the page. I find this stylistic choice dated and unneeded at this point in web design, function and readability should be at the top of the list before (possibly) unneeded flourish.
- I kept the code long in relation to line count, I wanted to style this page the long way, without refactoring at all, to continue to strengthen my foothold on CSS, once that is more sound will I then start to actively edit myself down after the fact.
- I chose not to make a mobile version at this time, frankly because I feel I have been looking at this project for too long and would like to move on to something new. I may come back and finish the mobile build in the future.
